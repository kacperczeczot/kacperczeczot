# 🛠️ scripts/ — Skrypty Narzędziowe

[🏠 Główny README](../README.md) / **scripts**

---

Katalog `scripts/` gromadzi skrypty deweloperskie i generatory assetów graficznych.

## 📄 Lista skryptów

1. **`generate-editorial-images.js`:**
   * Skrypt Node.js generujący spójne, wektorowe ilustracje SVG w palecie ciemno-oceanicznej (kadry archiwalne dla formacji muzycznych, portrety i okładki projektów).
2. **`generate-images.js`:**
   * Pomocniczy generator placeholderów i grafik bazowych SVG.
