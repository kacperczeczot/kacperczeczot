# 🖼️ public/ — Statyczne Zasoby Witryny

[🏠 Główny README](../README.md) / **public**

---

Katalog `public/` zawiera statyczne pliki serwowane bezpośrednio do przeglądarki bez przetwarzania przez Vite / Astro.

## 📂 Zawartość katalogu

* ⚙️ [**`admin/`**](admin/) — Przekierowanie do panelu [Pages CMS](https://app.pagescms.org).
* **`favicon.svg`** — Ikona witryny.
* **`images/`** — Pliki graficzne (zdjęcia, okładki, grafiki wektorowe i materiały archiwalne).
