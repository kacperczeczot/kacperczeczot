# ⚙️ Panel Administracyjny CMS (Sveltia)

[🏠 Główny README](../../README.md) / [public](../README.md) / **admin**

Panel **Sveltia CMS** działa na GitHub Pages. Zapis idzie do repozytorium przez API GitHuba — tylko konto z uprawnieniem `repo` (właściciel) może publikować zmiany.

* **Online:** https://kacperczeczot.github.io/admin
* **Lokalnie:** http://localhost:4321/admin (`npm run dev`)

Zaloguj się przyciskiem **Sign in with GitHub** albo tokenem PAT z uprawnieniem `repo`. Po **Save** GitHub Actions przebuduje stronę w ok. 30–60 sekund.
