# Edycja treści (Pages CMS)

Panel: [app.pagescms.org](https://app.pagescms.org)  
Wejście ze strony: [kacperczeczot.github.io/admin](https://kacperczeczot.github.io/admin/)

Zapisuje tylko konto GitHub z prawem zapisu do `kacperczeczot/kacperczeczot.github.io`. Publiczny link do `/admin` nic nie otwiera bez tego logowania.

## Pierwsze uruchomienie (raz)

1. Wejdź na [app.pagescms.org](https://app.pagescms.org) i zaloguj się GitHubem.
2. Zainstaluj aplikację **Pages CMS** na repozytorium `kacperczeczot/kacperczeczot.github.io` (GitHub → Settings → Applications albo kreator w Pages CMS).
3. W aplikacji otwórz to repozytorium i gałąź `main`.

## Codzienna edycja

1. Otwórz Pages CMS (albo `/admin` na stronie).
2. Wybierz **Strona główna**, **Bio**, **Formacje** albo **Projekty**.
3. Zapisz — powstaje commit na `main`.
4. Poczekaj ok. 30–60 sekund na GitHub Actions; potem odśwież publiczną stronę.
